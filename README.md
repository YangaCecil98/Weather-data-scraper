# Weather-data-scraper
A Python project for scraping, cleaning, and analyzing weather data 

## Project Overview

This project focuses on extracting weather data from a weather website
using Python and transforming the extracted information into a structured
dataset for analysis.

## Objectives

- Extract weather data from a website
- Parse HTML using BeautifulSoup
- Handle nested and semi-structured data
- Clean scraped data
- Convert extracted values into appropriate data types
- Store the data in a pandas DataFrame
- Perform exploratory data analysis
- Visualize weather patterns

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook
- Power BI

## Data Fields

- Location
- Time of Day
- Temperature
- Real Feel
